# مختبر التجارب العلمية التفاعلي - الصف الثاني عشر

## 🔬 نظرة عامة

تطبيق ويب تفاعلي شامل للتجارب العلمية للصف الثاني عشر في الفيزياء والكيمياء والأحياء. يحتوي التطبيق على **أكثر من 45 تجربة عملية** مع محاكاات تفاعلية مبنية على HTML5 و JavaScript.

## ✨ المميزات الرئيسية

### 1. المختبر التفاعلي
- **6 محاكاات تفاعلية كاملة** تعمل مباشرة في المتصفح
- وضعان للاستخدام: **وضع التعلم** (مع شرح) و **وضع التجربة** (تحكم كامل)
- رسوم متحركة واقعية باستخدام Framer Motion
- قياسات فورية ونتائج حية

### 2. قاعدة بيانات شاملة
- **45+ تجربة عملية** موثقة بالكامل
- تصنيف حسب المادة (فيزياء، كيمياء، أحياء)
- معلومات مفصلة: الأهداف، المكونات، الأجهزة، الخطوات، السلامة

### 3. واجهة مستخدم عربية متقدمة
- تصميم RTL كامل باللغة العربية
- خطوط Cairo و Noto Sans Arabic
- ألوان مميزة لكل مادة علمية
- تصميم responsive يعمل على جميع الأجهزة

### 4. نظام بحث وفلترة
- بحث نصي في العناوين والوحدات
- فلترة حسب المادة
- فلترة حسب المهارة العملية
- نظام مفضلة مع حفظ البيانات محلياً

## 🧪 المحاكاات التفاعلية المتوفرة

### الأحياء (3 محاكاات)
1. **النقل عبر الغشاء الخلوي** (`bio-membrane`)
   - محاكاة انتشار الجزيئات عبر الغشاء
   - تغيير التركيزات داخل وخارج الخلية
   - مشاهدة الوصول لحالة الاتزان

2. **تنفس الخميرة** (`bio-1-6`)
   - تأثير تركيز الجلوكوز على معدل التنفس
   - استخدام أزرق الميثيلين كمؤشر
   - قياس زمن تلاشي اللون

3. **التمثيل الضوئي** (`bio-3-7`, `bio-5-7`)
   - تأثير شدة الضوء وتركيز CO₂
   - مشاهدة إنتاج الأكسجين (فقاعات)
   - قياس معدل التمثيل الضوئي

### الكيمياء (1 محاكاة)
4. **معايرة pH حمض-قاعدة** (`chem-1-1`)
   - إضافة القاعدة تدريجياً للحمض
   - رسم منحنى المعايرة تلقائياً
   - تحديد نقطة التكافؤ

### الفيزياء (1 محاكاة)
5. **قانون التربيع العكسي للموجات** (`phys-1-6`)
   - تغيير المسافة عن المصدر
   - قياس الشدة عند كل مسافة
   - رسم العلاقة البيانية تلقائياً

### إضافة خاصة
6. **الانقسام الاختزالي** (`bio-1-1`)
   - عرض جميع أطوار الانقسام الاختزالي (9 أطوار)
   - رسوم متحركة للكروموسومات
   - شرح تفصيلي لكل طور

## 📚 التجارب المشمولة

### الفيزياء (12 تجربة)
- الإزاحة والسرعة
- التسارع
- الطاقة الحركية والوضع
- حفظ الطاقة
- الموجات والتردد
- قانون التربيع العكسي ⭐
- محزوز الحيود (قياس الطول الموجي)
- الموجات المستقرة
- ثابت بلانك
- التأثير الكهروضوئي
- الانحلال الإشعاعي

### الكيمياء (12 تجربة)
- قياس pH ⭐
- المعايرة حمض-قاعدة ⭐
- الخلايا الكهروكيميائية
- ثابت فارادي
- التحليل الكهربائي للماء
- المعقدات واستبدال الليجندات
- سرعة التفاعل (تأثير التركيز)
- العوامل المؤثرة في سرعة التفاعل
- نظرية التصادم
- خصائص العناصر الانتقالية
- خصائص البنزين
- نترتة البنزين (نظري)

### الأحياء (21 تجربة)
- فحص الخلية بالمجهر
- النقل عبر الغشاء ⭐
- الانتشار والأسموزية
- الانقسام المتساوي
- الانقسام الاختزالي ⭐
- الانتحاء الضوئي
- تنفس الخميرة ⭐
- التخمر
- تبادل الغازات في النبات ⭐
- التمثيل الضوئي (تأثير CO₂) ⭐
- فصل صبغات التمثيل الضوئي
- تشريح الكلية
- تنظيم الماء والأملاح

⭐ = تجارب بمحاكاة تفاعلية

## 🎨 التصميم والألوان

### نظام الألوان
- **الفيزياء**: `oklch(0.55 0.20 240)` - أزرق بنفسجي
- **الكيمياء**: `oklch(0.60 0.18 150)` - أخضر سماوي
- **الأحياء**: `oklch(0.58 0.16 120)` - أخضر طبيعي

### الخطوط
- **Cairo**: للعناوين والنصوص المهمة
- **Noto Sans Arabic**: للنصوص العادية والشروحات

## 🛠️ التقنيات المستخدمة

- **React 19** + **TypeScript**
- **Tailwind CSS v4** للتصميم
- **Framer Motion** للرسوم المتحركة
- **Shadcn UI v4** لمكونات الواجهة
- **Phosphor Icons** للأيقونات
- **Vite** كأداة بناء

## 📱 الاستخدام

### البحث والفلترة
1. استخدم مربع البحث للبحث عن تجربة معينة
2. اختر المادة (فيزياء/كيمياء/أحياء) للفلترة
3. اختر المهارة المطلوبة (قياس/تحليل/تخطيط...)
4. اضغط على زر "المفضلة" لرؤية التجارب المحفوظة

### فتح التجربة
1. اضغط على بطاقة التجربة
2. انتقل لتبويب "المختبر" إذا كانت التجربة لها محاكاة
3. اختر "وضع التعلم" لقراءة الشرح أو "وضع التجربة" للتحكم
4. اضبط المتغيرات واضغط "تشغيل"
5. شاهد النتائج والقياسات الحية

### تخصيص التجربة
- غيّر قيم المتغيرات المستقلة (التركيز، المسافة، الضوء...)
- راقب التغيرات في المتغيرات التابعة (الشدة، اللون، الزمن...)
- استخدم زر "إعادة ضبط" لبدء تجربة جديدة

## 🔬 هيكل البيانات

كل تجربة تحتوي على:
```typescript
{
  id: string                    // معرّف فريد
  subject: 'physics' | 'chemistry' | 'biology'
  grade: '12'
  term: '1' | '2'
  unit: string                  // رقم الوحدة
  unitTitle: string             // اسم الوحدة
  title: string                 // عنوان التجربة
  type: string                  // نوع التجربة
  objectives: string[]          // الأهداف
  components: string[]          // المكونات العلمية
  apparatus: string[]           // الأجهزة والأدوات
  materials: string[]           // المواد المستهلكة
  variables: {                  // المتغيرات
    independent: string
    dependent: string
    controlled: string[]
  }
  skills: string[]              // المهارات العملية
  stepsSummary: string[]        // ملخص الخطوات
  safety: string[]              // إرشادات السلامة
}
```
