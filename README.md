# 🧪 مختبر التجارب العلمية - الصف الثاني عشر

منصة تعليمية تفاعلية لتجارب العلوم (الفيزياء، الكيمياء، الأحياء) للصف الثاني عشر، مع مختبرات افتراضية ومولد اختبارات ذكي.

## 🌟 المميزات

### 🔬 مختبرات تفاعلية
- **42 تجربة علمية** مع محاكاة تفاعلية
- **عرض مرئي** لكل تجربة مع إمكانية التحكم بالمتغيرات
- **قياسات حية** ورسوم بيانية تتحدث مباشرة
- **تجارب واقعية** في الفيزياء، الكيمياء، والأحياء

### 🧠 مولد اختبارات ذكي
- **توليد اختبارات تلقائية** لكل تجربة
- **نماذج متعددة** بنفس الهيكل لكن ببيانات مختلفة
- **أسئلة استقصائية** شاملة (تخطيط، قياس، تحليل، تقييم)
- **جداول ورسوم بيانية** متغيرة

### 📊 تتبع الأداء
- **حفظ المفضلة** لكل طالب
- **متابعة التقدم** في التجارب
- **تحليل الأداء** حسب المهارات العملية

### 🎨 واجهة مميزة
- **تصميم عصري** باللغة العربية (RTL)
- **فلترة متقدمة** حسب المادة والمهارة
- **بحث ذكي** في جميع التجارب
- **استجابة كاملة** للهواتف والأجهزة اللوحية

## 🧪 المواد المتاحة

### ⚛️ الفيزياء (12 تجربة)
- قياس التسارع
- قانون التربيع العكسي للموجات
- قياس الطول الموجي بمحزوز الحيود
- الموجات المستقرة
- ثابت بلانك
- والمزيد...

### 🧪 الكيمياء (15 تجربة)
- المعايرة والرقم الهيدروجيني
- الخلايا الكهروكيميائية
- سرعة التفاعل الكيميائي
- المعقدات والليجندات
- التحليل الكهربائي
- والمزيد...

### 🧬 الأحياء (15 تجربة)
- النقل عبر الغشاء
- الانقسام المتساوي والاختزالي
- التنفس الخلوي
- التمثيل الضوئي
- الانتحاء الضوئي
- والمزيد...

## 🚀 التقنيات المستخدمة

- **React 19** + **TypeScript**
- **Tailwind CSS v4** للتصميم
- **Framer Motion** للحركات والانتقالات
- **Shadcn UI** لمكونات الواجهة
- **Phosphor Icons** للأيقونات
- **D3.js** للرسوم البيانية
- **Recharts** للرسوم التفاعلية
- **Spark Runtime SDK** للذكاء الاصطناعي والتخزين

## 📦 التثبيت والتشغيل

### المتطلبات
- Node.js 18 أو أحدث
- npm أو yarn

### خطوات التشغيل

1. **استنساخ المشروع**
```bash
git clone https://github.com/your-username/spark-template.git
cd spark-template
```

2. **تثبيت الحزم**
```bash
npm install
```

3. **تشغيل المشروع**
```bash
npm run dev
```

4. **فتح المتصفح**
```
http://localhost:5173
```

5. **تابع الأداء** والمهارات

## 🔧 الميزات المتقدمة

### مولد الاختبارات الذكي
- توليد أسئلة متنوعة لنفس التجربة
- بيانات وأرقام مختلفة في كل مرة
- جداول ورسوم بيانية متغيرة
- نماذج غير محدودة

### المختبرات التفاعلية
- محاكاة واقعية للتجارب
- تحكم كامل بالمتغيرات
- قياسات حية ودقيقة
- رسوم بيانية تفاعلية
- شرح علمي مفصل

### نظام التخزين
- حفظ التجارب المفضلة
- حفظ التقدم والنتائج
- مزامنة تلقائية
- لا يتطلب تسجيل دخول

## 🎨 التخصيص

### تغيير الألوان
عدّل الملف `src/index.css`:
```css
:root {
  --primary: oklch(0.45 0.15 265);
  --accent: oklch(0.65 0.22 50);
  ...
}
```

### إضافة تجربة جديدة
1. أضف البيانات في `src/data/experiments.ts`
2. أنشئ مكون المحاكاة في `src/components/simulations/`
3. اربطها بالتجربة
