# الميزات الذكية الجديدة - مختبر التجارب العلمية

## ✨ الميزات المضافة

### 1️⃣ مولّد اختبار الاستقصاء الذكي
**الملف**: `src/components/SmartQuizGenerator.tsx`

**الفكرة**:
- المعلم يضغط زر واحد → النظام ينشئ اختبار جاهز تلقائياً
- يستخدم الذكاء الاصطناعي (GPT-4) لتوليد أسئلة ذكية

**ماذا يفعل؟**:
- يختار التجربة
- يولد 5 أسئلة تغطي جميع مهارات الاستقصاء:
  1. تحديد المتغيرات (مستقل، تابع، ثابت)
  2. تصميم جدول بيانات مناسب
  3. نوع الرسم البياني والمحاور
  4. تحليل النتائج المتوقعة
  5. تقييم وتحسين التجربة ومصادر الخطأ

**الخصائص**:
- ✅ مطابق 100% للتعميم الكويتي
- ✅ أسئلة واقعية ومناسبة لمستوى الصف 12
- ✅ يمكن نسخ الاختبار أو تنزيله كملف نصي
- ✅ إعادة التوليد للحصول على أسئلة جديدة

**كيفية الاستخدام**:
```typescript
import { SmartQuizGenerator } from '@/components/SmartQuizGenerator'

<SmartQuizGenerator experiment={experiment} />
```

---

### 2️⃣ تحليل أداء الطلاب حسب المهارات
**الملف**: `src/components/StudentPerformanceTracker.tsx`

**الفكرة**:
- بدل درجة واحدة → يعطيك النتيجة مفصلة حسب كل مهارة
- تعرف أين الضعف بالضبط

**ماذا يعرض؟**:
```
المهارة          النتيجة
التخطيط          80%  ✓ ممتاز
جمع البيانات     60%  ✓ جيد
التحليل          40%  ⚠ مقبول
التقييم          30%  ❌ يحتاج تحسين
```

**الفائدة**:
- يساعد المعلم على معرفة المهارات التي يحتاجها الطالب للتحسين
- تقييم دقيق بدلاً من درجة واحدة
- تقارير بصرية مع ألوان وأيقونات

---

### 3️⃣ ربط (درس ↔ تجربة ↔ سؤال امتحان)
**الملف**: `src/components/LessonExamLinker.tsx`

**الفكرة**:
- يفهم الطالب: "هذا الدرس كيف يأتي في الاختبار"
- ربط واضح بين النظرية والتطبيق والامتحان

**ماذا يعرض؟**:
```
📘 الدرس النظري
        ↓
🧪 التجربة العملية
        ↓
📝 نمط السؤال في الامتحان
```

**مثال**:
```
الدرس: التمثيل الضوئي
   ⬇
التجربة: تأثير CO₂ على النبات المائي
   ⬇
السؤال: استقصاء عملي عن العوامل المؤثرة
```

**الفائدة**:
- الطالب يدرس بهدف واضح
- يفهم الارتباط بين الدراسة النظرية والتطبيق العملي
- يستعد بشكل أفضل للاختبارات

---

### 4️⃣ كشف أخطاء الطلاب تلقائياً
**الملف**: `src/components/ErrorDetectionAssistant.tsx`

**الفكرة**:
- النظام يكتشف الأخطاء الشائعة تلقائياً
- يعطي توجيهات فورية للطالب

**أمثلة الأخطاء التي يكتشفها**:
```
❌ رسم بياني بدون وحدات
   ✓ الحل: يجب كتابة وحدة القياس على كل محور

❌ لم يذكر متغير ثابت
   ✓ الحل: تأكد من ذكر جميع المتغيرات الثابتة

❌ نسي الوحدات في الجدول
   ✓ الحل: يجب أن يحتوي الجدول على عنوان واضح وأسماء الأعمدة والوحدات

❌ نسي إجراءات السلامة
   ✓ الحل: تذكر ارتداء النظارات والقفازات الواقية
```

**الفائدة**:
- تعلم فوري - الطالب يتعلم من أخطائه مباشرة
- تحسين جودة التقارير العلمية
- توفير وقت المعلم في التصحيح

## 📊 التقنيات المستخدمة

- **React Hooks**: useState, useKV للحفظ الدائم
- **Spark LLM API**: للذكاء الاصطناعي في توليد الاختبارات
- **Shadcn UI**: المكونات الجاهزة
- **Phosphor Icons**: الأيقونات
- **Framer Motion**: الحركات والانتقالات
- **TypeScript**: للتطوير الآمن

---

## ⚠️ ملاحظات مهمة

1. **مولد الاختبار** يحتاج إلى `spark.llm` API للعمل - هذا متوفر فقط عند التشغيل على منصة Spark
2. **تحليل الأداء** حالياً يعرض بيانات عشوائية - يحتاج إلى ربطه بنظام تقييم حقيقي
3. **كشف الأخطاء** يعرض أخطاء ثابتة - يمكن تطويره ليكون ديناميكياً مع الذكاء الاصطناعي
4. **الربط** يعمل بشكل كامل ويعرض معلومات التجربة الحقيقية
